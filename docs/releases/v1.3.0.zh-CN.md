# AgentCore OS v1.3.0 版本说明

`v1.3.0` 是当前推荐公开版本，重点不是继续扩展 app 数量，而是把现有系统收得更稳。

## 本版重点

- 将包版本、Tauri 桌面壳版本和当前入口文档统一到 `1.3.0`
- 增加本地 API 安全边界：高风险执行、LLM、媒体与凭据配置接口默认只接受本机请求
- 支持 `AGENTCORE_API_AUTH_TOKEN` 作为本地 API 额外保护
- 将 AgentCoreOS Runtime 默认权限从 `workspace-write` 收紧到 `read-only`
- 为媒体处理增加本地路径保护，避免任意读取机器上的文件
- 保留浏览器主线、发布队列、工作流状态和执行器会话的现有回归门禁

## 当前推荐方向

近期产品不应继续增加大量独立 app。默认优先级是：

1. 做深内容工作流：`Creator Radar -> Content Repurposer -> Publisher`
2. 做深销售工作流：`Deal Desk -> Email Assistant -> Personal CRM`
3. 把 scenario pack 从“可安装”推进到“可运行”
4. 继续收敛执行器、会话、审计和资产沉淀模型

## 验收建议

浏览器主线：

```bash
npm install
npm run test:stability
npm run dev
```

桌面 / runtime 主线：

```bash
npm run runtime:doctor
npm run desktop:smoke-test-sidecar
```

如果 `runtime:doctor` 提示 AgentCoreOS Runtime binary 未找到，需要先配置 `AGENTCORE_CLAW_CODE_BIN` 或把 runtime binary 加入 `PATH`。
