## 结论

这一阶段可以收尾。已登记的 `sales-pipeline-v1` 和 `support-resolution-v1` 会按剧本停在 `human_review`。销售资产、客服资产和知识资产只在批准后写入。驳回后继续执行返回 409，终稿不会落地。销售终稿还要再批准一次 `writeback` 才会写入。

Deal Desk 的「启动受控销售运行」走的是同一条受控运行接口。启动时不写销售资产。「生成简报」和「转到 Email Assistant」只更新线索或打开邮件，不再创建本地流程，也不再提前写入销售资产。

这不是一个已经回写外部 ERP 的系统。演示夹具的步骤输出是固定对象，不调用外部模型。

## 使用

开发服务可在仓库根目录执行 `npm run dev`，打开 `http://127.0.0.1:3000`。运行控制台点「用演示夹具启动」，或在 Deal Desk 选中线索后点「启动受控销售运行」。运行停在 `human_review`。批准后点继续，会再停在 `writeback`。第二次批准并继续，业务资产才写入。驳回后点继续，接口返回 409。
