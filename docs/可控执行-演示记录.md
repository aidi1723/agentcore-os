## 待复核草稿

2026-09-28 起，`approvalState` 为 `pending_review` 的草稿不能进入发布队列。发布台提供「批准草稿」。批准后状态成为 `approved`，预演和自动发布才可用。没有这个字段的手写草稿仍可入队。通用草稿保存不能把草稿直接写成已批准。

会读草稿、但还没有读 `approvalState` 的界面：

- `MorningBriefAppWindow`：晨报只引用标题和来源。运行入口是设计系统版本。
- `CreatorHeroWorkflowPanel`：按草稿 id 关联发布任务。发布台、选题雷达和内容改写会用到它。

其余运行中的窗口只调用 `createDraft`，不读取 `approvalState`。它们按钮上的「已发送」是把内容交给另一个窗口，不是创建发布任务。
